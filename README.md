# Nord-Gruvbox Arch Linux Rice (bspwm)

Монолітний, повністю автономний репозиторій для розгортання середовища `bspwm` у палітрі **Gruvbox Dark + Nord Blue** з інтерактивним інсталятором, вибором профілю обладнання та вбудованим модулем **Quote Library** для Eww Dashboard.

## Швидкий старт

```bash
git clone https://github.com/nikitasadoviy-wq/nord-gruvbox.git
cd nord-gruvbox
chmod +x install.sh
./install.sh
```

## Гарячі клавіші (sxhkd)

- `Super + Return` — Термінал (Alacritty)
- `Super + D` — Меню програм (Rofi)
- `Super + E` — Файловий менеджер у терміналі (Yazi)
- `Super + B` — Браузер (Firefox)
- `Super + G` — Відкрити/закрити Eww Dashboard (з Quote Library)
- `Super + Q` — Закрити вікно
- `Super + Shift + Q` — Примусово вбити вікно
- `Super + Alt + R` — Перезавантажити конфіг bspwm
- `Super + Escape` — Перезавантажити конфіг sxhkd
- `Super + [1-9]` — Перемикання робочих столів
- `Print` — Скріншот області в буфер обміну та `~/Pictures`
